# ARIST-post-retraction-citation

This repository stores code and data for "The landscape of epistemic risk and harm of retracted science: A scoping review of empirical research on post-retraction citation"

Code files
- code/DataCollection_2.1-ForwardAndBackwardCitations-UseIncludedOnly.ipynb: Code for performing citation searching
- code/Results.ipynb: Code for synthesis of results.

Data files
- data/225-included-in-Dimensions.csv: Seed articles used for citation searching
- data/manually_identified_ASJC_all.csv. This file lists articles for which two researchers manually examined and assigned subject areas.
- data/PostRetractionCitationData_20261119-EH_cleaned.csv. This file contains data extracted from the included studies.

- See data/README.md for details about each data file.
