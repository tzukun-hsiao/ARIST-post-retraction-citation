# ARIST-post-retraction-citation

This repository stores code and data for "The landscape of epistemic risk and harm of retracted science: A scoping review of empirical research on post-retraction citation"

Code files
1. code/DataCollection_2.1-ForwardAndBackwardCitations-UseIncludedOnly.ipynb: 
    - Python notebook for performing citation searching
2. code/Results.ipynb: 
    - Python notebook for synthesis of results


Data files
1. data/225-included-in-Dimensions.csv
    - Dataset content: This file lists seed articles used for citation searching.
2. data/manually_identified_ASJC_all.csv. 
    - Dataset content: This file lists articles for which two researchers manually examined and assigned subject areas.
3. data/PostRetractionCitationData_20261119-EH_cleaned.csv. 
    - Dataset content: This file contains data extracted from the included studies.
4. data/Included Studies and Secondary Reports.docx
    - Dataset content: Bibliographic data for included studies and secondary reports

**See data/README.md for details about each data file.**
